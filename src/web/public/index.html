Key capabilities

What it does

  • Intelligent task planningDecomposes complex queries into structured research steps.
  • Autonomous executionSelects and runs the right tools to gather financial data.
  • Self-validationChecks its own work and iterates until tasks are complete.
  • Real-time financial dataIncome statements, balance sheets and cash flow statements.
  • Safety featuresBuilt-in loop detection and step limits prevent runaway execution.

How it works

A research plan, executed and verified.

Dexter takes a complex financial question and breaks it into steps. It runs those steps against live market data, reviews what came back, and refines the results until the answer holds up. The loop stops on its own if it detects it is going in circles or reaches its step limit.

Inspect every step

Nothing is hidden.

Every tool call is logged to a scratchpad file: the original query, each call with its arguments and raw result, and the agent's reasoning. You can see exactly what data it gathered and how it read it.

Questions

Before you start.

Prerequisites: Bun, a model provider key, and a Financial Datasets key. An Exa key is optional, for web search.

Which API keys do I need?

An OpenAI API key (other providers are optional) and a Financial Datasets API key. An Exa API key is optional and enables web search.

Can I use other model providers?

Yes. Besides OpenAI, Dexter supports Anthropic, Google, xAI, Moonshot, DeepSeek, OpenRouter and Ollama Cloud. Pick one and add its key on the Settings page.

Is this investment advice?

No. Dexter is for educational, entertainment and informational purposes only. Outputs may be incorrect, incomplete or out of date. Consult a licensed financial advisor before making investment decisions.

How do I debug a result?

Open the newest file in .dexter/scratchpad/. Each line is a JSON entry recording the query, each tool result and the agent's reasoning steps.
